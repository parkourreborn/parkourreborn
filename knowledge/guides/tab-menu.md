## Overview

The tab menu is an interface consisting of multiple other menus that display vital information about the game, player statistics, items stored within the inventory, and more. It is accessible via pressing TAB on keyboard, SELECT on controller, or clicking the red hamburger button at the top left next to the Roblox menu.

## Menus

 Side

* Tab Menu: Opening will display your credits and tokens balance, as well as multiple buttons that lead to other menus.

* Player: Showcases rank & level. Accessible by clicking on the person icon.

* Stats: Details various statistics about yourself (playtime, deaths, etc.)

* Abilities: Displays every ability (both movement and combat) you've unlocked. Clicking on an ability's icon will pop-up a small menu showcasing each aspect of the ability, alongside a GIF of it in action.

* Inventory: Contains gear, resources, key items, valuables, and consumables.

* Cosmetics: An inventory for all gear skins obtained from bags.

* Missions: Contains all active missions. You can track them via right clicking.

* Music: Where music tracks are played from. Accessible by clicking on the music note icon in the top left.

* Playlist: Has manageable playlists of music tracks. Currently, only the primary one is available.

* Settings: Includes options for adjusting gameplay, controls, graphics, the interface, and more. The Environment Tweens setting, formerly called Window Tweening, controls tweening for windows and district atmospheres.

* Tutorials: Currently empty and serves no purpose. It will eventually explain more about the game's mechanics that you learn over time, allowing players to reference them at any point. Accessible by clicking on the question mark icon next to the settings button.

 Pop-Up

* Exit to Hub: Sends you back to The Hub when clicked on. Replaces the tab menu's button when it is open.

* Store: The store menu.

* Premium Inventory: Stores skins, emotes, and other premium items. Accessible by clicking on the icon next to the store's.

* Purchase Tokens: Purchasable packs of tokens for Robux. Accessible by clicking on the wallet icon next to your balance of credits and tokens. Hovering over the Robux cost displays the 1 to token value.

* Loadout: Shows what gear you're currently wearing. Accessible by clicking on the tools icon.

* Crafting: The crafting menu.

* Daily Rewards: Players gain currency upon joining the game every 24 hours. They earn credits every day until the end of the week, where they earn a little bit of tokens instead. Rewards increase in the subsequent week.

* The Net: Only accessible by pressing THE NET keybind (editable in the controls settings). The Net is a window resembling a web browser.

## Trivia

* The abilities side menu was accidentally added in an incomplete state upon the release of alpha 1.1; it was later added back in a more complete, but still somewhat unfinished, state upon the release of alpha 1.14.

* It has been completed as of alpha 1.2.

* Before the game had its own custom-made soundtrack, it used Downtown Binary's Aurora Album.

* The full Reborn soundtrack will be released onto Spotify at some point.

* Prior to alpha 1.73 the keybind for 'HIDE UI' in controls is set to KeypadMinus—which does not have a proper icon—and thus showed as an "ERROR" instead.

* The Coffee theme gives a noticeable tint to the white UI characters. Jet Black has a similar tint, but it's less noticeable. Every other UI theme doesn't have a tint effect.

* The 1500 Robux token offer actually has a 1.2933... conversion rate, but it's rounded up to 1.3 when you hover over it.

## Quick Facts

The Tab Menu contains multiple game menus and can be opened by:
* pressing Tab on keyboard,
* pressing Select on controller,
* clicking the red hamburger button near the Roblox menu.

### Side Menus

| Menu | Purpose |
| :---- | :---- |
| Tab Menu | Shows Credits, Tokens, and menu buttons |
| Player | Shows rank and level |
| Stats | Shows playtime, deaths, and other statistics |
| Abilities | Shows unlocked abilities with icons, details, and GIFs |
| Inventory | Contains gear, resources, key items, valuables, consumables |
| Cosmetics | Inventory for gear skins |
| Missions | Active missions; can be tracked by right-clicking |
| Music | Music tracks |
| Playlist | Manage music playlists |
| Settings | Controls, graphics, interface, gameplay options |
| Tutorials | Currently empty; intended to explain mechanics later |
