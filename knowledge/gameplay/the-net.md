The Net is an imitation of the internet in-world, and functions as a browser in the game. It hosts a variety of websites players can access to learn more about the game and its various aspects.
Note: it can only be accessed by using its dedicated keybind (Y for most people, changeable in the control settings), or through the player list in the upper right corner.

## FEATURES

* SEARCH BAR: This is where you enter the address for websites. It is located at the top of the window.

* REFRESH: This button refreshes the website you're currently on. It is located to the left of the search bar.

* BACKWARDS & FORWARDS: These buttons enable you to navigate to the previous or next page respectively. They are located to the very left of the search bar.

* BOOKMARKS: Websites can be bookmarked for easy access by clicking the star icon in the search bar next to the address, and entering the desired bookmark's name. Bookmarked websites can be accessed by clicking on their respective icon to the right of the star.

## Quick Facts

The Net is an in-world imitation of the internet. It functions like a browser inside Parkour Reborn.

Access:
* dedicated keybind, usually Y,
* changeable in control settings,
* through the player list in the upper right.

### Browser Controls

| Control | Purpose |
| :---- | :---- |
| Search Bar | Enter website addresses |
| Refresh | Refresh current page |
| Back / Forward | Navigate browser history |
| Bookmarks | Save websites for easy access |

Invalid links return:
* error 400 Bad Request
