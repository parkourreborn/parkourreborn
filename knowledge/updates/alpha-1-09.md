Alpha 1.09 was released on January 10, 2024 (build 90).

## Changes

* All-new custom chat!
  * Only players in proximity can hear you, to talk to the entire server, you must be connected to a transceiver

* The tutorial can now be skipped and retried
* Bronze is now the time trial's time limit
* Changed "Shift Lock" keybind to "Cycle Camera"
  * Cycle Camera cycles between Default, First-Person Lock, and Shift Lock

* Dash lasts longer
* Adjusted various platinum medals
* Additive jump velocity now capped to 45 instead of 28
* Fixed an issue where long jumping did not choose a launch direction if you released movement input
* Fixed pads occasionally just deciding to kill you
{{Hotfix|name=SMALL UPDATE|date=January 12, 2024}}
* Significant performance improvements! (Turn down the render distance in Reborn settings if you're still laggy)
* Added a setting for depth of field
* Bug fixes
