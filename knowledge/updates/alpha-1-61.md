Alpha 1.61 was released on October 28, 2025 (build 199). It was the Halloween 2025 seasonal update.

## Optimizations
Still chipping away at it!
* Optimized the Halloween candy spawning script
* Optimized fabric couches, fabric armchairs, standing ladders, climbable ladders, water towers, metal scaffolding, and vending machines
* Archived some old props that were rarely used and were unoptimized
* Added DetailLevel to more of the map

## Miscellaneous Tweaks
* Tweaked some parts of Downtown to be more beginner friendly
* Required candies for Halloween badge reduced to 25 from 50
* You can now sit in the black chairs commonly found in Dirwik!
* Removed the Halloween bats (in a previous hotfix, never documented, sorry!)
* Added more swing points around the map
* Tweaked Derek's dialog in the Discover Landmarks mission to more closely fit his character
* New option in the debug ghost editor to record time trial runs
* Updated badge icons on the site
* Restored lighting settings that we had previously tweaked (Note: Unfortunately, this means black voids in reflective surfaces may appear when fake first person shadows are enabled. Turn off fake first person shadows to fix this)

## Bug Fixes
* Fixed some badges not being awarded when they should have been
* Replaced old Advancement Alpha/Beta badges with new ones because they were improperly given out before
* Fixed a NaN bug breaking your game and allowing you to fly
* Fixed chocolate bar text being upside down on one side
* Fixed lemon mode not properly restoring some prop's textures after disabling it sometimes
* Fixed some infinite loading errors
* Fixed being able to spam the exit loiter animation
* The time trial timer should no longer disappear randomly
* Tokens earned from daily rewards henceforth will not be reset when resetting your data. However, any Tokens earned from daily rewards before this update will unfortunately be lost if you reset your data, we're sorry for the inconvenience.
* Fixed a vent type floating slightly off the ground
* Fixed XP routers floating slightly off the ground
* Fixed some destructible vents becoming stuck in the wall
