Alpha 1.52 was released on August 31, 2025 (build 188).

## Free Period For 5 Days
Enjoy a free period for 5 days!

## Springhook
You are now able to obtain the Springhook gear! With the use of the Springhook, you can fall from much greater heights and save yourself by catching an edge! Find Connor’s workshop in Dirwik to learn more about this gear!

## Ui Themes
UI themes are now available! You are able to purchase them through the Premium passes tab and access them in your Premium inventory!

## Token Gifting
You can now gift Tokens to other people in your game! Simply open the Token shop and click on the gift icon below the Token bundle you want to gift!

## Upgrading Gears
You are now able to upgrade your gears with Premium Tokens through the new upgrade gears tab! You can get to this tab by going to the gear page in the store, or clicking the upgrade icon in the description of your gear.

## Map Adjustments
As always, we are continuing to refine the map.
* Vertigo and Artemis have received rebalances to make them easier
* Some barren areas now have more detail, such as in Dirwik and Fragment
* Dirwik has a few new interiors
* The golden/ruby vent interior has been reworked

## Miscellaneous Tweaks
* Buffed Mag Pull’s distance
* Mag Rail’s Pipe Glide now has a sound
* Infinite climb grates now no longer consume wall ammo and can be climbed without wall ammo
* The metal sheet at the start of the Dash trial has been removed
* Added Zipline Hook and Cable Glider to the gear shop
* Rounded the Combo UI and recolored the raw combo score number to make it more readable
* Many UI elements have been slightly recolored to work better with UI themes
* Most tall planters have been retextured
* Content Creators now have their own chat color
* Chat colors have all been changed following a vote from Premium Members
* You can now disable chat colors for readability purposes
* Added the model for the remaining placeholder Mag Rail, Grappler, and Glove parts
* Added the model for the electronics valuable
* All metal sheets have been hitboxed
* Many grates in Downtown have been hitboxed
* Set Gale time trial to Moderate difficulty
* Tweaked Token store values and icons

## Bug Fixes
* Fixed spectate requests not working
* Fixed cheating in time trials using race shenanigans
* Fixed the map not working for some users
* Fixed daily rewards
* Fixed race invites sometimes not working
* Fixed deliveries breaking (potentially)
* Fixed buying bulk items in shops not visually updating properly
* Fixed spectating and party highlights interacting weirdly
* Fixed an issue where Tokens/credits would clip into shop item count
* Fixed broken loiter with grappler
* Fixed text clipping in the compass
* Fixed some valuable pickup prompts flashing or being hard to pick up
* Fixed the owned tag in the gear shop not being fully shadowed when other gear was highlighted
* Fixed some checkpoints being on floors with DetailLevel, causing the player to fall through the map when spawning in on them
* Optimized hover in inventory items
* Removed the old "Learn Afterboost" mission from the NPC Mantra
