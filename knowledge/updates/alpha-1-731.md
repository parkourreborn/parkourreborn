Alpha 1.731 was released on October 17, 2026 (build 290). It was the Halloween 2026 seasonal update. It is the newest update of PARKOUR Reborn.

## Halloween
Our yearly Halloween event is now enabled! Happy Halloween everyone!

* Explosive pumpkins will spawn around the map, granting instant speed when touching them
* Candies will float around the map, collect them to earn free XP
  * Collect enough to get a seasonal badge!
* NPCs will change outfits, if they have a Halloween costume for the season
* Lighting is Halloween themed
* Some props are reskinned, like checkpoints

## Miscellaneous Tweaks
* Added a new animation for grappler's rope retracting
* Grappler may now be used on ladders
* Cancelling moves with descend is now on key press rather than key release
* Breaking glass has been improved in several ways
  * It’s now way more optimized
  * Glass can now be irregular shapes
  * Glass collides with the world when broken
  * When using grappler, glass will crack when the grappler makes contact, but only fully shatter when pulled
* New wood and carpet footstep sounds
* Minor optimizations to several scripts
* Tweaked loading screen
* Reduced server start times
* Fixed Signal Booster not always working correctly
