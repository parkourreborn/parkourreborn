Pre-Alpha 1.2 was released on November 6, 2023 (build 45).

## Changes

* Custom player list

  * **NEW TIME TRIAL**
* Apollo, near the south west corner of Downtown

* Buffed powerslide speed boost
* Certain materials are now infinitely climbable

* Minor optimizations
* Gaining rank stars now has an animation
* Zipline prompts now appear properly
* You can now view any changelogs from pre-alpha 1.1 onwards
* Button prompts on controller should now display the correct images based on your console
* Server size back down to 50, vc doesnt work above 50
