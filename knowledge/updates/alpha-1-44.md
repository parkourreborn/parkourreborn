Alpha 1.44 was released on July 18, 2025 (build 181).

## Changes

These additional fixes and changes listed below were initially part of 1.5, but since the entire scripts for chat had to be moved over to here, they've come alongside Roblox's service migration. If you find any bugs with it, don't bother telling us, as we know of them all already; we just wanted to get this hotfix out to you all as soon as possible.

* Fixed being able to type in chat while its box was closed,
* Fixed special characters being inserted at the start of chat messages on certain keyboards,
* Fixed the text cursor in chat snapping to the end of your written message if you tried inserting a character at any other point,
* Fixed chat bubbles appearing way above the player’s head,
* Combo/Chain announcements in the chat box now disappear after a bit

Note: This update is a minor hotfix from the previous update, and therefore the description is the same as 1.43.
